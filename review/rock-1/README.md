# Локальная проверка ROCK 1

Скриншоты сняты в настоящем Chromium. Публичные изображения заменены явно обозначенными тестовыми изображениями; фотографии артиста в рабочем сайте загружаются по сохранённым ссылкам. Числа в админке — демонстрационные данные локальных проверок, не посещаемость рабочего сайта.

JSON-отчёты перечисляют реально выполненные сценарии. Внешние Google/Firebase/Cloudflare, почта и Telegram заменены управляемыми тестовыми ответами. Производственных изменений эти проверки не выполняли.
