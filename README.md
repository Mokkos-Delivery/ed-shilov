# Эдуард Шилов — ROCK 3

Публичные страницы без Firebase SDK, оптимизированные изображения на Hosting и восстановление подключения хранилища. Второй администратор и упрощённая студия сохранены. Рок-дизайн публичного сайта, предложения концертов и выступлений, статистика посещений и всех треков в сохранённой студии Studio 4.

[Скачать ZIP обновления](https://github.com/Mokkos-Delivery/ed-shilov/raw/refs/heads/codex/rock-site-analytics/downloads/EDUARD_ROCK3_UPDATE_2026-11-12.zip)

- [Установка в Windows](project/UPDATE-ROCK-WINDOWS.md)
- [Статистика: подключение и значения показателей](project/ANALYTICS.md)
- [Изменения и проверка](project/REPORT-ROCK-3.md)

Архив содержит `project/`, `source/`, `audit.json` и `media-inventory.json` прямо в корне. Все четыре нужны для сборки. Распакуйте поверх существующего `C:\eduard-site`; рабочие настройки, подтверждение правил Firestore, секреты и медиа не заменяются. GitHub Code → Download ZIP создаёт дополнительную папку-обёртку; инструкция рассчитана на ZIP по ссылке выше.

Для разработки: Node.js >=24.12.0, ffprobe (FFmpeg), `cd project`, `npm ci`, `npm test`, `npm run prepare`, `npm run check`. Черновая сборка не предназначена для публикации. Браузерные тесты используют Chromium и Python Playwright с локальными сервисами и тестовыми изображениями; они не отправляют письма или Telegram-посты.

Статистика требует настройки D1 и публикации Worker. Показываются только новые события посетителей, разрешивших аналитику. На рабочий сайт эти исходники автоматически не публикуются.

Дизайн этой версии построен на публичных страницах текущего репозитория. Архив «эд.zip» не был прочитан: он превысил лимит передачи 32 МБ. Для точного переноса его страниц нужен архив с HTML/CSS/JS и изображениями до 32 МБ, без node_modules и больших медиа.

Старые `PROMPT_NEXT_CHAT.md`, `SETUP.md`, `DEPLOY.md`, `REPORT-2026-10-29.md` сохраняют историю Studio 4. Для ROCK 3 используйте инструкцию выше.
