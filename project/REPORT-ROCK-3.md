## Публичный сайт

- Firebase SDK полностью исключён из зависимостей публичных страниц. Новый небольшой модуль запрашивает нужный каталог через `/api/catalogue` Worker при открытии страницы и возвращении в её вкладку/окно (не чаще 30 секунд). Постоянных Firestore Listen-каналов у посетителя нет. SDK остаётся в студии.
- Worker читает Firestore анонимно, с фильтром `published == true`, по прежним правилам доступа. Нельзя запросить произвольную/приватную коллекцию. Учитывается флаг начального наполнения каталога. Кеш успешного результата — 15 секунд; параллельные запросы объединяются. Ошибка/слишком большой результат не выдаются как успешный пустой каталог.
- Исправлено удаление `srcset` и повторная загрузка оригинальной обложки при обновлении каталога. Для статических карточек сохраняется соответствие исходной записи; неизменившиеся видеокарточки тоже используются повторно. В списке песен задан реальный размер обложки 78 px.
- `prepare:images -- --apply` скачивает публичные статические иллюстрации и обложки, создаёт WebP 320/640/1280, сохраняет локальный кеш и переносит варианты в Hosting при сборке. Имена определяются содержимым, кеш браузера — год. Настройки/оригиналы Drive не изменяются. Эти байты не включены в ZIP: они обрабатываются на машине владельца перед публикацией. При отсутствии подготовленных вариантов остаётся прежняя доставка через Worker. Команда работает с каталогом исходной сборки; новые материалы админки по-прежнему доступны через Worker.
- Публичный CSS минифицирован и включён в HTML: отсутствует отдельная блокирующая загрузка таблиц стилей. Hero больше не получает стартовую анимацию перемещения. Стили сохраняют прежнее оформление. Добавлен preconnect к медиа-сервису; шрифты и подготовленные изображения кешируются на год, скрипты и отдельный CSS — на сутки с версионированием URL.
- Удалён неиспользуемый запрос `/assets/media-variants.json`, добавлены метаописания и карта исходников Firebase bundle. Прежние метаданные заголовков сохранены.
